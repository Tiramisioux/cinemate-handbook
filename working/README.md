# working/

Task-shaped how-to pages — the directory you'll open most often. Pick the page that matches
what you're about to do: [`changing-a-control.md`](changing-a-control.md) for a Redis key,
controller method, or settings key; [`changing-the-gui.md`](changing-the-gui.md) for either
UI surface; [`changing-the-installer.md`](changing-the-installer.md) for install-time
behavior; [`testing.md`](testing.md) for what to run and what to write;
[`hardware-session.md`](hardware-session.md) for how to settle a claim that needs the real
device;
[`clearhdr-campaign-overseer-prompt.md`](clearhdr-campaign-overseer-prompt.md) for the
ready-to-paste opening prompt of the overseer thread running the ClearHDR stabilisation
campaign (one experiment per round, operator-observed, pre-registered predictions).
